# OROK Companion

OROK companion material is optional downstream enrichment for Atlas editions. It is not part of the mandatory Atlas release path unless an edition explicitly opts into it before production.

For AOC-001, the human-approved scope decision is recorded in `AOC001-OROK-SCOPE-DECISION.md`: no OROK companion is required to complete the end-to-end Atlas test or release this edition.

If an OROK companion is produced later, it should be treated as a separate educational/cultural derivative. Keep local expression specific rather than flattening it into a universal stereotype, and preserve the Atlas fact/fiction/evidence boundaries.
