# AOC-002 original contextual media

These originals provide geographical, working-life and industry context for the hypothetical Eastern Niger Delta drilling-pad failure. Use a visible context label and the actual location when known. Keep these shots clear of any edit that implies the depicted people, rigs or places were involved in the fictional failure.

Wikimedia Commons supplies the creator, location and licence for each file. The location descriptions below reflect what each source records. Originals are unmodified. All three videos decoded without errors. The vertical review compared original framing with a 9:16 center crop using sampled frames across each clip.
